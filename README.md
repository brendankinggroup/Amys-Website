# Pilates High

Single-page marketing site for Amy's private Pilates apparatus training in Las Vegas.

Plain HTML, CSS, and a few lines of JavaScript. No build step: open `index.html` in a browser, or serve the folder with any static host (GitHub Pages, Netlify, Vercel).

## Files

- `index.html` — all page content. Search for `[bracketed]` text and the `<!-- Placeholder -->` comments; those are the facts Amy needs to confirm (certifications, years teaching, rates, phone, email).
- `styles.css` — design tokens at the top, light and dark themes, then components.
- `script.js` — the breathing line in the hero (four seconds in, six seconds out). Respects `prefers-reduced-motion`.

## Before launch

1. Replace the bracketed placeholders in the Amy section.
2. Confirm the four rates in the Investment section.
3. Set the real email in the form `action` and the phone number in the Begin section.
4. Drop a portrait photograph into the `.portrait` block.
